## <a id="access">Access Information</a>

The data in the 0.1 release is available in different ‘packages’, (a) the [complete Common Pile](https://huggingface.co/collections/common-pile/common-pile-v01-raw-data-6826b454a5a6a445d0b51b37), (b) a [filtered sub-set](https://huggingface.co/collections/common-pile/common-pile-v01-filtered-data-68300bb0a946d10dda697663), and (c) a “[slightly modified and consolidated version](https://huggingface.co/datasets/common-pile/comma_v0.1_training_dataset)” used to train the Comma v0.1 language models.

# The Stack

**[DRAFT] (Version 1.2; July 2026)**

## <a id="background">Background</a>

The Stack ([Kocetkov et al., 2022](https://arxiv.org/abs/2211.15533)) is a large-scale collection of permissively-licensed source code files developed by the BigCode project for training code language models. Version 1.2 covers 358 programming languages sourced from GitHub repositories created between January 2015 and March 2022, and incorporates opt-out requests submitted by February 2023 as well as removal of initially flagged malicious files.
Additional details are available on the [HuggingFace dataset page](https://huggingface.co/datasets/bigcode/the-stack).

## <a id="sources">Data Sources</a>

GitHub repositories collected via [GHArchive](https://www.gharchive.org/). Approximately 51.76B files were downloaded, of which 5.28B unique files were retained after filtering to permissive licenses only (copyleft licenses excluded as of v1.1). Near-deduplication was applied using MinHash and Locality Sensitive Hashing (Jaccard similarity >= 0.85), removing roughly 40% of files.

## <a id="statistics">Structure & Statistics</a>

The dataset is distributed as 6,827 Zstd-compressed JSONlines files across 360 programming language subdirectories, amounting to 1.4 TB on disk.
Files are stored under `data/<language>/` and follow the naming pattern `train-NNNNN-of-NNNNN.jsonl.zst`.

**Note:** The primary text field in this dataset is `content`, not `text`.

## <a id="access">Access Information</a>

The primary download site for the data is the [HuggingFace Hub](https://huggingface.co/datasets/bigcode/the-stack).

Developers may request removal of their code via the [Am I In The Stack?](https://huggingface.co/spaces/bigcode/in-the-stack) tool.

On select EuroHPC systems, the data is directly available for read-only access on the local filesystem:

+ LUMI: `/appl/local/openeurollm/training/catalogue/the-stack/1.2/data/`
+ Leonardo: `/leonardo_work/openeurollm/training/the-stack/1.2/data/`
